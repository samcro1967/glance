## Custom API

Custom API examples demonstrate complete integrations built with the [Custom API widget](widgets/custom-api.md), including reusable templates, example configuration, expected JSON data, and minimal data producers where an external API cannot be consumed directly by Glance.

### Monitoring

The monitoring examples use a shared Custom API presentation pattern so different services can produce a consistent dashboard experience while keeping service-specific data collection outside Glance.

See [Custom API Monitoring](examples/custom-api/monitoring/README.md) for the shared monitoring template and available integrations.
